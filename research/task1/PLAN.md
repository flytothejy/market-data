# 과제 1 — 실적 서프라이즈 예측: 사전 등록 계획

> 작성·고정 2026-10-24 (신호 결과를 보기 전). 이후 변경은 이 파일 아래 "변경 이력"에 날짜·이유와 함께만 추가한다.

## 1. 이벤트와 데이터
- 이벤트: 종목별 과거 실적 발표 1건. 예상 EPS와 실제 EPS가 둘 다 있는 발표(대략 2005~).
- 출처: yfinance `get_earnings_dates` (발표 시각·예상·실제 EPS), yfinance 일봉(수정주가), SEC 8-K 항목 2.02 접수 시각(R2 `sec/filings`), 내부자 거래(R2 `sec/insider_hist`, 2010~), 공매도 거래량(R2 `short/volume`, 2010~).
- 발표 시각: yfinance 시각과 8-K 접수 시각을 교차 확인한다. 둘이 어긋나면 8-K를 우선하고, 둘 다 없으면 반응 분석에서 제외한다.
- 반응일: 장전(09:30 이전) 발표는 당일, 장후(16:00 이후) 발표는 다음 거래일.
- 반응: 반응일 종가 ÷ 직전 거래일 종가 − 1. 초과반응 = 반응 − SPY 같은 날 수익률.
- 한계: 현재 유니버스 종목만 있다(상장폐지 없음) → 생존편향이 결과를 좋게 보이게 만든다.

## 2. 목표 (3개)
- Y1 상회 여부: 판정 = round(실제,2) − round(예상,2) ≥ 0.01. 기준선 두 가지와 비교한다.
  - B1: 같은 해 전체 상회율
  - B2: 그 종목의 직전 8분기 상회율 (최소 4분기 있어야 계산)
- Y2 서프라이즈 크기: (실제−예상)/|예상|이 같은 달력 분기 발표들의 중앙값보다 큰가. |예상| < 0.05면 제외.
- Y3 주가 반응: 반응일 초과수익의 방향과 크기. 거래 환산은 발표 직전 종가 매수 → 반응일 종가 매도(숏은 반대). 비용은 편도 0.05%(민감도 0.02%, 0.1%).
  - 기준선: 같은 칸 모든 이벤트의 평균, 같은 종목 무작위 발표.

## 3. 후보 신호 (정의·변형 고정)

## 4. 검증 절차
- 4칸 분할: 종목 A/B(시가총액 10분위 안 무작위, 시드 20261024) × 반응일 연도 홀/짝.
  - 설계 = A×홀, 확인① = A×짝, 확인② = B×홀, 최종 = B×짝.
  - 연말 10거래일·연초 10거래일 이벤트는 분할표에서 제외한다.
- 합격 기준:
  1. 설계 칸에서 기준선보다 낫다.
  2. 확인① 과 확인② 모두에서 같은 방향으로 유의하다 (단측 p < 0.05, 날짜별 묶음 표준오차).
  3. Y3은 비용(편도 0.05%)을 넣어도 양수다.
  4. 1~3을 모두 통과한 신호만 최종 칸을 한 번 본다.
- 국면·시기 분할: SPY가 200일 이평 위/아래인 국면, 시기(~2009 / 2010–14 / 2015–19 / 2020~). 결과가 뒤집히면 탈락 또는 '조건부'로 표시한다.

## 7. 추가 가설 — S7 실적 발표 후 표류 (PEAD) (2026-10-24 등록, S1~S5 결과를 본 뒤 추가)
- 질문: 서프라이즈나 다음 날 반응이 컸던 종목이 **반응일 다음 날부터** N거래일 동안 같은 방향으로 더 움직이는가.
- 진입: 반응일 종가(정보 공개 후). 목표 Y4_N = 종목 누적수익(반응일 종가 → +N거래일 종가) − SPY 같은 기간. N = 20, 60.
- 신호 (설계 칸 분위 경계, 모든 칸에 적용):
  - s7_surp_top: 서프라이즈 크기 ≥ 80% 분위 (가설 +)
  - s7_surp_bot: 서프라이즈 크기 ≤ 20% 분위 (가설 −)
  - s7_ear_top: 반응일 초과수익 ≥ 80% 분위 (가설 +)
  - s7_ear_bot: 반응일 초과수익 ≤ 20% 분위 (가설 −)
- 검정 4 × 2 = 8. 효과 D = E[Y4|S=1] − E[Y4|S=0]. 보유 기간이 겹치므로 묶음 표준오차는 **반응일의 달(연-월)** 단위로 한다.
- 4칸: 보유 기간이 연말을 넘어가는 이벤트는 제외한다(홀/짝 해 분리를 지키기 위해 — 60일 보유에서는 약 4분의 1이 빠진다).
- 판정은 §4와 같다. 비용: S=1 이벤트 매수(− 방향은 공매도) 원수익 − 왕복 0.1% > 0.
- 이 가설은 S1~S5 결과를 본 뒤 추가했다. 그래서 시도 횟수(log.csv)에 합산하고, 보고서에도 그렇게 적는다.

## 8. 생존편향 재검증 1R (2026-10-25 등록, 결과 보기 전)
- **범위**: 상장폐지 종목은 예상 EPS 이력이 없다(yfinance 미제공, EODHD 요금제 밖). 그래서 **Y1·Y2(실적 예측)는 다시 검증하지 않고**, 주가 반응 쪽만 다시 본다. Y1·Y2 결과의 생존편향은 한계로 남긴다.
- **상장폐지 이벤트**: 과제 5 R과 같은 상장폐지 회사(SEC CIK 연결 + EODHD 가격, 금융 포함)의 SEC 8-K 항목 2.02.
  - 시각: 접수 시각(UTC → 뉴욕). 09:30 전이면 장전, 16:00 이후면 장후, 장중은 제외한다.
  - 같은 회사의 직전 채택 이벤트로부터 45일 안의 2.02 공시는 버린다(정정·부속 공시).
- **지금 유니버스 이벤트**: 기존 events.csv 그대로 쓴다.
- **공통 필터**: 반응일 2005-01-01 이후, 반응일 직전 252거래일 하루 평균 거래대금 ≥ 2천만 달러.
- **수익률**: 반응일 수익률·초과수익(SPY 대비)은 기존 정의 그대로. Y4 보유 중 거래가 끊기면 마지막 가격에서 현금으로 둔다.
- **4칸**: 지금 종목은 기존 배정, 상장폐지 종목은 코드 MD5 첫 바이트 홀/짝. 반응일 연도 홀/짝, 연말·연초 각 10거래일 제외.
- **검정 8개** (경계값은 이 유니버스 설계 칸에서 다시 계산)
  - S3 → Y3: s3_20_top, s3_20_bot, s3_5_top, s3_5_bot (모두 D > 0 방향)

  - 서프라이즈 기반 S7은 예상 EPS가 없어 제외한다.
- **판정**: §4·§7과 같다(Y3는 날짜 묶음, Y4는 월 묶음 표준오차, 비용 왕복 0.1%).
- **기술 통계**: 반응 기본 비율(평균 초과반응, 오른 비율, 반응 폭 중앙값)을 지금 종목만 / 상장폐지 포함으로 비교한다.
