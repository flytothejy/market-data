# 과제 2-7 — 주식분할 예측: 사전 등록 계획

> 작성·고정 2026-10-25 (결과 보기 전, 분할 자료 수집만 한 상태). 코드 폴더 `task12`, log 태그 `T12-`. 공통 규약: `../PLAN_phase2.md`.

## 1. 질문
- 가. 반응 확인: 주식분할 전후 주가는 어떻게 움직이나.
  - 발표일 자료가 없어서 분할 효력일(배당락처럼 주가가 나뉘는 날) 기준으로 본다.
  - 발표는 대개 효력일 1~2개월 전이라, 발표 반응은 효력일 전 60일 구간에 들어간다.
- 나. 사전 예측: 앞으로 분할할 회사를 "주가 수준이 높다"는 단순 규칙보다 잘 고를 수 있나.

## 2. 사건
- 자료: EODHD 분할 이력(`data/raw/eodhd/splits_R.csv`), 과제 1-5 R 패널 종목 전체(지금 종목 + 상장폐지).
- 사건 = **정방향 분할 비율 ≥ 1.5**(예: 3:2, 2:1, 10:1)의 효력일. 주식 배당 형태의 작은 비율과 역분할은 뺀다.
- **목표**: 예측일 다음 날부터 90일 뒤 ~ 365일 안에 효력일이 있으면 1.
  - 90일 안의 분할은 이미 발표됐을 가능성이 커서 뺀다. 그런 예측일은 표본에서 제외한다.
- 효력일부터 365일 안의 예측일도 뺀다(직후 재분할은 드물다).

## 3. 표본과 특징
- 과제 1-5 R 패널(수정판), 분기 초 예측일 2011-01 ~ 2024-10, 회사 기준 중복 제외.
- **B1**: log(실제 주가, 분할 미반영). 높을수록 분할 가능성이 높다고 본다.
- **M (로지스틱, 설계 칸에서만 맞춤)**: B1 + 아래 특징
  | ID | 정의 |
  |---|---|
  | x_ret1 | 직전 1년 시장 대비 수익률 |
  | x_ret3 | 직전 3년 시장 대비 수익률 |
  | x_size | log 시가총액 |
  | x_nsplit | 직전 10년 정방향 분할 횟수 |
  | x_since | 마지막 분할 뒤 연수(최대 15, 없으면 15) |
  | x_px_rel | 주가 ÷ 같은 날 표본 주가 중앙값의 로그 |
  - 결측·절단은 과제 2-2와 같다.

## 4. 평가
- 칸: 종목 배정 × 예측일 연도 홀/짝.
- **검정 3개**
  1. B1 AUC > 0.5
  2. M AUC − B1 AUC > 0
  3. M 상위 10% 적중 − B1 상위 10% 적중 > 0
- p값: 예측일 블록 부트스트랩 2,000회, 단측.

## 5. 반응 확인 (가)
효력일 기준, SPY 대비:
- [−60, −2]: 발표 반응 포함
- [−1, +1]
- [+2, +250]: 분할 뒤 1년. 기존 연구(Ikenberry 외)는 양의 표류를 보고했다.

## 6. 한계
- 발표일을 모른다. 효력일 기준이라 발표 반응을 따로 떼어 보지 못한다.
- 분할 자료의 정확성은 몇 건을 원자료와 대조한다.
