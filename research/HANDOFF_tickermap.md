## 0. 공통 원칙 (사이트 기존 결정과 맞춤)
- 정보·고르는 도구·알림을 준다. **추천이나 "~할 것" 표현은 쓰지 않는다.**
- **'검증' 표시는 쓰지 않는다.** 과거 통계는 ? 아이콘 뒤 짧은 문장으로만 보여준다.
- 안내 문구는 최소로 한다. 방향(오를지/내릴지)은 어떤 기능에서도 표시하지 않는다.
- 숫자는 "과거 같은 조건 회사의 비율" 형태로 쓴다. 개별 종목 확률처럼 보이게 쓰지 않는다.
- 유사투자자문업 위험이 있다. 개인별 매수·매도 판단은 주지 않는다. 유료화 전 법률 검토가 필요하다.
- 데이터 라이선스: yfinance는 비상업 조건이다. 연구에 쓴 EODHD 상장폐지 자료는 사이트에 쓰지 않는다. 사이트는 SEC 공시와 사이트 자체 가격 수집만 쓴다.

## 2. ① 부실 위험 등급
**입력** (예측일 = 계산하는 날, 그 전에 공시된 값만):
| 변수 | 정의 | 절단 범위 |
|---|---|---|
| nz | −Altman Z. Z = 1.2·(유동자산−유동부채)/총자산 + 1.4·이익잉여금/총자산 + 3.3·영업이익(TTM)/총자산 + 0.6·시가총액/총부채 + 1.0·매출(TTM)/총자산 | [−46.48, 4.89] |
| nimta | 순이익(TTM) ÷ (시가총액 + 총부채) | [−0.199, 0.174] |
| tlmta | 총부채 ÷ (시가총액 + 총부채) | [0.0079, 0.869] |
| cashmta | 현금및현금성자산 ÷ (시가총액 + 총부채) | [0.0004, 0.252] |
| exret | 직전 252거래일 로그수익 − SPY 로그수익 | [−1.212, 1.062] |
| sigma | 직전 63거래일 일간 로그수익 표준편차 | [0.0068, 0.0686] |
| rsize | ln(시가총액, 달러) | [18.42, 26.35] |
| price | ln(min(실제 주가, 15)), 분할 미반영 실제 가격 | [1.279, 2.708] |

- SEC 태그: Assets, Liabilities, AssetsCurrent, LiabilitiesCurrent, RetainedEarningsAccumulatedDeficit, OperatingIncomeLoss, NetIncomeLoss, Revenues(없으면 RevenueFromContractWithCustomerExcludingAssessedTax → SalesRevenueNet), CashAndCashEquivalentsAtCarryingValue.
- 시가총액: 실제 주가 × 주식수.
  - 주식수 = 표지 주식수(dei, 같은 공시의 종류별 합). 재무제표 희석 가중평균 주식수와 0.5~2배 안이면 쓰고, 아니면 희석 주식수를 쓴다.
  - **분할 반영 가격으로 시가총액을 계산하면 안 된다.**
- 결측: 그 변수를 설계 중앙값으로 채우고, 결측 표시 m_변수 = 1. 계수와 중앙값은 spec JSON에 있다.
- 점수: `logit = const + Σ b·x + Σ b_m·m` → `p = 1/(1+e^(−logit))`.
  - **화면에는 p를 쓰지 않는다. 같은 날 대상 종목 안에서의 순위로 등급을 매긴다.**

**등급과 과거 통계** — ⚠ §11 Q1로 대체됨(고정 점수 기준값 + 대형 집단 비율). 아래는 연구 전체 집단·순위 기준 참고값
| 등급 | 순위 | 과거 1년 내 부실 비율 |
|---|---|---|
| 매우 높음 | 상위 1% | **18.2%** |
| 높음 | 1~5% | 1.6% |
| 주의 | 5~10% | 0.6% |
| 보통 | 나머지 | 0.07% |
| (전체) | | 0.33% |

**문구** (? 뒤): "같은 등급 회사의 과거 1년 내 파산·부실 상장폐지 비율 18.2% (전체 0.3%)."
- 근거 칩을 함께 표시한다: 변동성 높음 / 부채 비율 높음 / 주가 낮음 / 적자 / 1년 수익률 부진. 각 변수가 그날 대상 종목 상위 20%면 칩을 켠다.

**알림**: 후보함·관심 포트폴리오 종목이 '높음' 이상으로 올라가면 텔레그램으로 1회 보낸다.

**알려진 오탐**: 금융 자회사 부채가 큰 회사(예: 포드), 상장 직후 변동성이 큰 회사.

## 3. ② 실적 발표 예상 변동폭
- 대상: 실적 발표 예정 종목. 초과수익 = 종목 일간수익 − SPY 일간수익.
- 반응일 = 장전 발표면 당일, 장후 발표면 다음 거래일.
- **화면 기본(단순 규칙)**: "지난 8번 발표 평균 ±x%"(반응일 |초과수익| 평균, 최소 4회).
  - 과거에 상위 20%로 예측된 발표의 44%가 실제 상위 20%였다(무작위 20%).
- **보조: 이번 시즌 같은 업종 평균** = 같은 SIC 2자리, 반응일 전 90일 안 다른 종목 반응 |초과수익| 평균(5건 미만이면 전체 평균).
- **모델 예상치**(선택):
  - `ln|변동| = −0.074 + 0.511·f1 + 0.197·f2 + 0.306·f3 + 0.226·f4 − 0.004·f5 + 0.025·f6`
  - f1 = ln(과거 8회 평균 |반응|)
  - f2 = ln(직전 60일 일간 초과수익 표준편차)
  - f3 = ln(업종 시즌 평균)
  - f4 = ln(1 + |직전 20일 시장 대비 수익|)
  - f5 = ln(거래대금)
  - f6 = 장후 발표 1/0
  - 순위상관은 단순 규칙보다 약 0.02 높다. 화면에는 단순 규칙을 먼저 보여준다.
- 문구: "지난 8번 실적 발표 평균 ±8.1% · 이번 시즌 같은 업종 ±6.3%." ? 뒤: "방향은 표시하지 않습니다."

## 4. ③ 배당 점검표
- 대상: 분기 배당 회사. 배당 간격 중앙값 80~100일이고, 직전 배당 뒤 45일 안의 배당은 특별배당으로 본다.
- **증액 패턴**: 작년 같은 분기의 다음 배당이 증액이었으면 "매년 m월경 인상".
  - 과거: 그런 경우 다음 배당 증액 **76%**, 아닌 경우 6%.
  - 최근 인상률과 연속 무삭감 연수를 함께 표시한다.
- **삭감 점검**: 배당수익률(최근 배당 × 4 ÷ 실제 주가)의 같은 분기 대상 내 순위, 지난 1년 시장 대비 수익률, 배당성향(배당수익률 ÷ 이익수익률).
| 조건 | 과거 1년 내 삭감·중단 비율 |
|---|---|
| 배당수익률 상위 10% | 20.4% |
| 배당수익률 상위 10% + 1년 −20% 이하 | **27.4%** |
| 배당수익률 하위 50% | 2.9% |
| 전체 | 5.2% |
- **변동배당 회사 표시**: 이력상 삭감(직전 대비 −0.5% 이상 감소)이 3번 이상인 회사(SCCO, DVN 등)는 "변동배당"으로 표시하고 증액·삭감 판단에서 뺀다.
- 배당 발표 당일 주가 반응은 작다(증액 +0.6%, 삭감 −0.6%). 반응 수치는 화면에 쓰지 않는다.

## 6. ⑤ 지수 편입 근접도
- **S&P 500**: 비편입 종목 중 요건을 모두 만족하는 종목의 시가총액 순위를 보여준다.
  - 요건: 미국 본사, 최근 분기 순이익 > 0, 최근 4분기 합 > 0, 유동성 기준(과제 1-3 PLAN).
  - 과거에는 상위 10개 중 12개월 안 편입이 약 27%였다(그냥 큰 비편입 종목의 2배).
  - 편입 후보를 들고 있어도 수익은 없었다(−2.0%p). 수익 표현은 쓰지 않는다.
- **Nasdaq-100**: 나스닥 상장(Global Select·Global Market), 비금융, 외국 기업 포함 시가총액 순위.
  - 표시 예: "기준 100위 / 기존 구성 종목은 125위까지 유지".
  - 과거 재현은 부정확했다(거래소 이력 부족). 순위 사실만 보여준다.
- 문구 예: "10월 말 기준 나스닥 비금융 시가총액 **87위**."

## 7. 설명 지표 (예측 아님)
- 역DCF 내재 성장률: 정의 D(`reports/1-5_재무신호_역DCF.md` §5)를 그대로 쓴다. 입력값은 모두 화면에 공개한다. 예시 숫자는 §10 F5대로 다시 계산하고, 문구의 '검증'은 지운다.
- 피인수 조건: "같은 업종(SIC 2자리) 최근 2년 인수 비율 x%, 업종 내 규모 하위 y%." 업종 회사 수가 10개 미만이면 표시하지 않는다.
- 분할 이력: 과거 분할 목록 + "최근 15년 분할 없음·고가 유지 회사" 표시.

- 기록 시점: distress·div_cut·split·index_near는 분기 첫 거래일 장 마감 뒤. earn_move는 발표 전날. 매일 기록해도 되며, 연구 쪽은 분기 첫 거래일 파일만 채점한다.

### Q8. 역DCF 보류 → 동의
- 연구 쪽에서 먼저 해야 할 이유는 없다. 순위를 정할 때는 F5(예시 재계산, '검증' 문구 삭제)만 지켜 달라.

## 12. 구현 쪽 2차 전달(2026-10-26)에 대한 답 (spec `version 2026-10-26c`)
> 이 절이 §11보다 우선한다.

### 1. 접수 시각(accepted) — **R2 쪽 오류는 맞다. 다만 "일괄 +시차 보정"은 30%의 종목을 망가뜨린다**
- SEC 원본 submissions JSON의 `acceptanceDateTime`은 **진짜 UTC**다. 예: NVDA 0001045810-26-000073 = 20:21:19Z = 뉴욕 16:21. 머리말과 일치한다.
- R2 `hub/sec/filings.parquet`의 accepted를 원본과 비교했다(8-K 11.2만 건).

  | R2 − 원본 | 건수 | 비율 |
  |---|---|---|
  | +4시간 | 52,202 | 46% |
  | +5시간 | 24,850 | 22% |
  | **0 (정상)** | 35,225 | **31%** |

- **종목 단위로 갈린다.** 1,012종목 중 617종목은 전부 밀려 있고, 299종목은 전부 정상이다(예: CMG, DRI). 96종목은 섞여 있다(최근 증분 수집분은 정상).
  - 수집 경로(초기 일괄 적재 vs 증분)에 따라 다르게 저장된 것으로 보인다.
- 그래서 지금의 `earnmove.py` 보정(뉴욕 변환 뒤 시차를 한 번 더 더함)은 정상인 31%를 4~5시간 **앞당긴다**. 정상 종목의 장후 16:05 발표가 12:05 '장중'이 된다.
  - 장 전 비율이 37% → 48%로 바뀐 것도 일부는 이 과보정 탓일 수 있다.
- **권고**: 시차를 일괄 보정하지 말고, accepted를 **SEC submissions JSON에서 다시 채운다**.
  - recent + 이전 페이지, 종목당 1~3회 호출이다.
  - 수집 코드에서 시각이 밀리는 경로를 찾아 고친다. 이후 공시는 원본 값을 그대로 저장한다.
  - `hub/derived/earn_moves.parquet`도 그 뒤 다시 만든다.
- **연구 결과 영향**: 거의 없다. 연구는 접수 시각을 두 곳에서 썼다.
  - ① 상장폐지 회사 실적 이벤트: SEC 원본 JSON에서 직접 읽어 정상이다.
  - ② 지금 종목 실적 이벤트(과제 1-1 → R 이벤트 → 2-1): R2 값을 썼다. 다만 장중으로 밀린 건은 yfinance 발표 시각으로 대체되는 규칙이 있었다.
  - 원본 시각으로 다시 계산해 보니, 반응일이 달라진 이벤트는 7.4만 건 중 **84건(0.1%)**, 실제로는 장중 발표였는데 장전·장후로 쓴 이벤트는 421건(0.6%)이었다.
  - → 과제 2-1의 평균 변동폭·44% 적중·계수는 **다시 계산할 만큼 바뀌지 않는다.** spec `earnings_move`는 그대로 둔다.
  - 다른 과제(13D·피인수·파산·배당·분할 반응)는 공시일(filingDate)만 써서 영향이 없다.

### 2. 실적 2.02 중복 규칙(테슬라) — **구현 쪽 규칙이 더 낫다. 그대로 쓰라**
- 연구의 지금 종목 이벤트는 yfinance 실적 일정(EPS 발표일) 기준이었다. 2.02는 시각 확인에만 썼다. 그래서 인도량 공시는 섞이지 않았다.
- 상장폐지 회사 이벤트는 "45일 안 첫 2.02"를 써서 비슷한 오염이 일부 있을 수 있다. 상장폐지 회사 비중이 작아 결론에는 영향이 작다.

### 3. 부채 총계 결측 — **파생값으로 바꾸고, 새 계수를 쓰라**
- 연구 모델도 같은 문제가 있었다. 학습 데이터의 tlmta 결측 43%, nimta 50%, Z 57%였고, 결측은 중앙값 + 결측 표시로 처리했다.
- 그래서 파생값만 넣고 기존 계수를 쓰면 맞지 않는다. **같은 파생 규칙으로 다시 맞췄다**(`task10/outclean2/`, log `T10clean2-`).
  - 총부채 = Liabilities, 없으면 (LiabilitiesAndStockholdersEquity, 없으면 Assets) − StockholdersEquityIncludingPortionAttributableToNoncontrollingInterest(없으면 StockholdersEquity). 0 이하이면 결측.
  - 결측 비율: tlmta 43% → 11%, nimta 50% → 23%, Z 57% → 35%.
- **결과**
  - 모델 AUC 0.91~0.96(4칸 모두)이다.
  - 등급 기준값은 거의 같다: 매우 높음 p ≥ 0.0550, 높음 ≥ 0.0067, 주의 ≥ 0.0029.
  - 대형 집단 비율: 매우 높음 7.4%(108건), 높음 1.5%, 주의 0.6%, 보통 0.07%.
  - **새 계수·절단·중앙값은 spec에 반영했다.**
- 참고(연구 판정): 부채를 채우자 Altman Z도 좋아졌다(최종 AUC 0.85). 그래서 "모델이 Z보다 낫다" 검정은 이 민감도에서 최종 칸 p = 0.064로 경계선이다.
  - 모델 자체의 판별력은 오히려 올랐다. 화면용으로는 모델을 쓴다.
- 현재 결과(높음 4, 주의 10, 매우 높음 0)는 대형주 위주 집단이라 자연스럽다. 새 계수로 다시 계산해 달라.

### 4. 특별배당 2.5배 규칙 — **채택. 연구 통계도 이 규칙으로 갱신했다**
