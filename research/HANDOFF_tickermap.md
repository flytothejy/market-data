## 0. 공통 원칙 (사이트 기존 결정과 맞춤)
- 정보·고르는 도구·알림을 준다. **추천이나 "~할 것" 표현은 쓰지 않는다.**
- **'검증' 표시는 쓰지 않는다.** 과거 통계는 ? 아이콘 뒤 짧은 문장으로만 보여준다.

## 2. ① 부실 위험 등급
**입력** (예측일 = 계산하는 날, 그 전에 공시된 값만):
| 변수 | 정의 | 절단 범위 |
|---|---|---|
| nz | −Altman Z. Z = 1.2·(유동자산−유동부채)/총자산 + 1.4·이익잉여금/총자산 + 3.3·영업이익(TTM)/총자산 + 0.6·시가총액/총부채 + 1.0·매출(TTM)/총자산 | [−46.48, 4.89] |
| nimta | 순이익(TTM) ÷ (시가총액 + 총부채) | [−0.199, 0.174] |
| tlmta | 총부채 ÷ (시가총액 + 총부채) | [0.0079, 0.869] |
| cashmta | 현금및현금성자산 ÷ (시가총액 + 총부채) | [0.0004, 0.252] |
| exret | 직전 252거래일 로그수익 − SPY 로그수익 | [−1.212, 1.062] |
| sigma | 직전 63거래일 일간 로그수익 표준편차 | [0.0068, 0.0686] |
| rsize | ln(시가총액, 달러) | [18.42, 26.35] |
| price | ln(min(실제 주가, 15)), 분할 미반영 실제 가격 | [1.279, 2.708] |

- SEC 태그: Assets, Liabilities, AssetsCurrent, LiabilitiesCurrent, RetainedEarningsAccumulatedDeficit, OperatingIncomeLoss, NetIncomeLoss, Revenues(없으면 RevenueFromContractWithCustomerExcludingAssessedTax → SalesRevenueNet), CashAndCashEquivalentsAtCarryingValue.
- 시가총액: 실제 주가 × 주식수.
  - 주식수 = 표지 주식수(dei, 같은 공시의 종류별 합). 재무제표 희석 가중평균 주식수와 0.5~2배 안이면 쓰고, 아니면 희석 주식수를 쓴다.
  - **분할 반영 가격으로 시가총액을 계산하면 안 된다.**
- 결측: 그 변수를 설계 중앙값으로 채우고, 결측 표시 m_변수 = 1. 계수와 중앙값은 spec JSON에 있다.
- 점수: `logit = const + Σ b·x + Σ b_m·m` → `p = 1/(1+e^(−logit))`.
  - **화면에는 p를 쓰지 않는다. 같은 날 대상 종목 안에서의 순위로 등급을 매긴다.**

**등급과 과거 통계** (2011~2024, 예측 뒤 12개월 안 파산 공시 또는 부실 상장폐지 비율)
| 등급 | 순위 | 과거 1년 내 부실 비율 |
|---|---|---|
| 매우 높음 | 상위 1% | **18.2%** |
| 높음 | 1~5% | 1.6% |
| 주의 | 5~10% | 0.6% |
| 보통 | 나머지 | 0.07% |
| (전체) | | 0.33% |

**문구** (? 뒤): "같은 등급 회사의 과거 1년 내 파산·부실 상장폐지 비율 18.2% (전체 0.3%)."
- 근거 칩을 함께 표시한다: 변동성 높음 / 부채 비율 높음 / 주가 낮음 / 적자 / 1년 수익률 부진. 각 변수가 그날 대상 종목 상위 20%면 칩을 켠다.

**알림**: 후보함·관심 포트폴리오 종목이 '높음' 이상으로 올라가면 텔레그램으로 1회 보낸다.

**알려진 오탐**: 금융 자회사 부채가 큰 회사(예: 포드), 상장 직후 변동성이 큰 회사.

## 3. ② 실적 발표 예상 변동폭
- 대상: 실적 발표 예정 종목. 초과수익 = 종목 일간수익 − SPY 일간수익.
- 반응일 = 장전 발표면 당일, 장후 발표면 다음 거래일.
- **화면 기본(단순 규칙)**: "지난 8번 발표 평균 ±x%"(반응일 |초과수익| 평균, 최소 4회).
  - 과거에 상위 20%로 예측된 발표의 44%가 실제 상위 20%였다(무작위 20%).
- **보조: 이번 시즌 같은 업종 평균** = 같은 SIC 2자리, 반응일 전 90일 안 다른 종목 반응 |초과수익| 평균(5건 미만이면 전체 평균).
- **모델 예상치**(선택):
  - `ln|변동| = −0.074 + 0.511·f1 + 0.197·f2 + 0.306·f3 + 0.226·f4 − 0.004·f5 + 0.025·f6`
  - f1 = ln(과거 8회 평균 |반응|)
  - f2 = ln(직전 60일 일간 초과수익 표준편차)
  - f3 = ln(업종 시즌 평균)
  - f4 = ln(1 + |직전 20일 시장 대비 수익|)
  - f5 = ln(거래대금)
  - f6 = 장후 발표 1/0
  - 순위상관은 단순 규칙보다 약 0.02 높다. 화면에는 단순 규칙을 먼저 보여준다.
- 문구: "지난 8번 실적 발표 평균 ±8.1% · 이번 시즌 같은 업종 ±6.3%." ? 뒤: "방향은 표시하지 않습니다."

## 4. ③ 배당 점검표
- 대상: 분기 배당 회사. 배당 간격 중앙값 80~100일이고, 직전 배당 뒤 45일 안의 배당은 특별배당으로 본다.
- **증액 패턴**: 작년 같은 분기의 다음 배당이 증액이었으면 "매년 m월경 인상".
  - 과거: 그런 경우 다음 배당 증액 **76%**, 아닌 경우 6%.
  - 최근 인상률과 연속 무삭감 연수를 함께 표시한다.
- **삭감 점검**: 배당수익률(최근 배당 × 4 ÷ 실제 주가)의 같은 분기 대상 내 순위, 지난 1년 시장 대비 수익률, 배당성향(배당수익률 ÷ 이익수익률).
| 조건 | 과거 1년 내 삭감·중단 비율 |
|---|---|
| 배당수익률 상위 10% | 20.4% |
| 배당수익률 상위 10% + 1년 −20% 이하 | **27.4%** |
| 배당수익률 하위 50% | 2.9% |
| 전체 | 5.2% |
- **변동배당 회사 표시**: 이력상 삭감(직전 대비 −0.5% 이상 감소)이 3번 이상인 회사(SCCO, DVN 등)는 "변동배당"으로 표시하고 증액·삭감 판단에서 뺀다.
- 배당 발표 당일 주가 반응은 작다(증액 +0.6%, 삭감 −0.6%). 반응 수치는 화면에 쓰지 않는다.

## 6. ⑤ 지수 편입 근접도
- **S&P 500**: 비편입 종목 중 요건을 모두 만족하는 종목의 시가총액 순위를 보여준다.
  - 요건: 미국 본사, 최근 분기 순이익 > 0, 최근 4분기 합 > 0, 유동성 기준(과제 1-3 PLAN).
  - 과거에는 상위 10개 중 12개월 안 편입이 약 27%였다(그냥 큰 비편입 종목의 2배).
  - 편입 후보를 들고 있어도 수익은 없었다(−2.0%p). 수익 표현은 쓰지 않는다.
- **Nasdaq-100**: 나스닥 상장(Global Select·Global Market), 비금융, 외국 기업 포함 시가총액 순위.
  - 표시 예: "기준 100위 / 기존 구성 종목은 125위까지 유지".
  - 과거 재현은 부정확했다(거래소 이력 부족). 순위 사실만 보여준다.
- 문구 예: "10월 말 기준 나스닥 비금융 시가총액 **87위**."

## 7. 설명 지표 (예측 아님)
- 역DCF 내재 성장률: 정의 D(`reports/1-5_재무신호_역DCF.md` §5)를 그대로 쓴다. 입력값은 모두 화면에 공개한다.
- 피인수 조건: "같은 업종(SIC 2자리) 최근 2년 인수 비율 x%, 업종 내 규모 하위 y%." 업종 회사 수가 10개 미만이면 표시하지 않는다.
- 분할 이력: 과거 분할 목록 + "최근 15년 분할 없음·고가 유지 회사" 표시.
