# 과제 2-4 — Nasdaq-100 연말 재구성 예측: 사전 등록 계획

> 작성·고정 2026-10-25 (결과 보기 전). 코드 폴더 `task9`, log 태그 `T9-`. 공통 규약: `../PLAN_phase2.md`.
> 규칙 출처: Nasdaq-100 방법론 문서(2026판), 2023-11 방법론 의견 수렴 문서.

## 1. 질문
- 가. 반응 확인: 12월 정기 재구성의 편입·편출 발표는 주가를 움직이나(발표 반응, 발표~효력일, 효력일 이후 되돌림).
- 나. 사전 예측: 공개 시가총액으로 **지수 규칙을 그대로 흉내 낸 예측**(B1)이 실제 편입·편출을 얼마나 맞히나.
  - 단순 순위 규칙(B0)보다 나은가.

## 2. 정답
- 위키백과 'Nasdaq-100' 문서에서 재구성 전(11월 30일 이전 마지막)과 후(1월 15일 이전 마지막) 판본을 받는다.
  - 구성 종목 차이 = 그해 12월 재구성의 편입·편출.
  - 같은 기간의 수시 교체가 섞일 수 있다. 원자료 대조로 몇 해를 확인한다.
- 기간: 2011~2025년 12월 재구성(SEC 재무 자료가 쌓인 이후).
- **평가 대상은 우리 풀 안의 종목뿐**: 미국 본사, 금융·부동산 제외, 거래대금 ≥ 2천만 달러, 지금 종목 + 상장폐지. 외국 기업(ASML, AZN, PDD 등)은 뺀다.
  - 외국 기업 구성 종목은 자리만 차지하는 것으로 본다: 우리 풀에 배정되는 자리 = 100 − (재구성 전 구성 종목 중 풀 밖 종목 수).

## 3. 예측
- **예측 시점** = 11월 첫 거래일. 기준 = 10월 마지막 거래일 시가총액.
  - 시가총액 = 그날 실제 주가(분할 미반영) × 주식수(과제 1-5 R 패널과 같은 함수, 2026-10-25 수정판).
- **나스닥 상장 여부**
  - 지금 종목: 프로필 거래소(NMS·NGM·NCM).
  - 상장폐지 종목: EODHD 마지막 거래소가 NASDAQ인 경우.
  - 위키백과 구성 종목에 있었던 적이 있으면 나스닥으로 본다.
- **B1 (규칙 흉내)**, 우리 풀 순위 기준:
  ① 상위 75위 선택
  ② 기존 구성 종목 중 100위 안 유지
  ③ 기존 구성 종목 중 101~125위는 작년 우리 순위가 100위 안이었으면 유지
  ④ 남은 자리는 비구성 종목을 순위대로 채움
- **B0 (단순 순위)**: 우리 풀 상위 N(배정 자리 수)을 그대로 구성 종목으로 본다.
- 예측 편입 = 예측 구성 − 기존 구성. 예측 편출 = 기존 구성 − 예측 구성.

## 4. 평가
- 칸: 종목 배정(A/B, 과제 1-5와 같음) × 재구성 연도 홀/짝. 칸마다 편입·편출 사건을 모은다.
- 지표: 편입·편출 각각의 정밀도(예측한 것 중 실제 비율), 재현율(실제 중 예측한 비율), F1.
- **검정 3개**
  1. B1 편입 정밀도 > 기준 발생률. 기준 = 우리 풀 상위 150위 안 비구성 종목 중 실제 편입 비율.
  2. B1 편출 정밀도 > 기준 발생률. 기준 = 기존 구성 종목 중 실제 편출 비율.
  3. **B1 F1 − B0 F1 > 0** (편입+편출 합산)
- p값: 연도 단위 블록 부트스트랩 2,000회, 단측.
- 합격: 확인①·② 모두 p < 0.05 → 최종 칸 1회. log `T9-`.

## 5. 반응 확인 (가)
- 발표일
  - 효력일 = 12월 셋째 금요일 다음 거래일.
  - 발표 = 효력일 6거래일 전 장 마감 뒤. 반응일은 그다음 거래일이다.
  - 실제 발표일과 다를 수 있다. 몇 해를 보도 자료와 대조한다.
- 구간 (SPY 대비)
  - 반응일 [0, +1]
  - 반응일 +2 ~ 효력일 전날 종가
  - 효력일 ~ +20거래일(되돌림)
  - 예측 시점(11월 첫 거래일) ~ 발표일 종가(사전 반영)
- 대상: 편입 / 편출 / B1이 예측한 편입 중 실제 편입 / B1이 예측했으나 편입 안 됨.
