# 과제 2-5 — 부실(파산·부실 상장폐지) 경고: 사전 등록 계획

> 작성·고정 2026-10-25 (결과 보기 전). 코드 폴더 `task10`, log 태그 `T10-`. 공통 규약: `../PLAN_phase2.md`.

## 1. 질문
- 가. 반응 확인: 파산 신청 공시(8-K 항목 1.03) 전후로 주가가 얼마나 움직이나. 사전 하락이 얼마나 되나.
- 나. 사전 예측: 앞으로 12개월 안 부실 사건을 고전 지표인 **Altman Z**보다 잘 맞힐 수 있나.
  - 시장 정보를 넣은 모델(Campbell·Hilscher·Szilagyi 2008 방식)과 비교한다.

## 2. 사건 정의 (회사 = CIK 단위)
부실 사건일은 다음 중 가장 이른 날이다.
- (a) **8-K 항목 1.03**(파산·법정관리) 공시일
- (b) **부실 상장폐지**: 상장폐지 회사 중 아래 세 조건을 모두 만족하는 경우의 마지막 거래일
  - 피인수 정답(과제 2-2의 합병 공시 규칙)에 없다.
  - 마지막 실제 주가가 2달러 미만이거나, 마지막 252거래일 수익률이 −70% 이하다.
  - SEC 상태가 '다른 티커로 계속 공시(still_filing_other_ticker)'가 아니다.

## 3. 표본
- 과제 1-5 R 패널(2026-10-25 수정판). 분기 초, 지금 종목 + 상장폐지, 금융·부동산 제외, 거래대금 ≥ 2천만 달러.
- 예측일 2011-01 ~ 2024-10. 같은 회사가 두 티커로 있으면(예: ACI와 ACIIQ) 예측일마다 한 줄만 쓴다.
- 목표: 예측일 다음 날 ~ 365일 안에 부실 사건일이 있으면 1.
- 사건일부터 730일 안의 예측일은 뺀다(이미 부실 상태).

## 4. 특징 (예측일 전 공시·가격만)
- **B1: Altman Z** = 1.2·운전자본/총자산 + 1.4·이익잉여금/총자산 + 3.3·영업이익(TTM)/총자산 + 0.6·시가총액/총부채 + 1.0·매출(TTM)/총자산
  - 점수가 낮을수록 위험하다.
  - 계산이 안 되면 결측이다. 결측은 설계 칸 중앙값과 표시 변수로 처리한다.
- **M (로지스틱, 설계 칸에서만 맞춤)**: Z + 다음 변수
  | ID | 정의 |
  |---|---|
  | nimta | 순이익(TTM) ÷ (시가총액 + 총부채) |
  | tlmta | 총부채 ÷ (시가총액 + 총부채) |
  | cashmta | 현금 ÷ (시가총액 + 총부채) |
  | exret | 직전 252거래일 시장 대비 로그 초과수익 |
  | sigma | 직전 63거래일 일간 수익률 표준편차 |
  | rsize | log 시가총액 |
  | price | log(min(실제 주가, 15)) |
  - 비율 변수는 설계 칸 1%/99%로 절단한다.

## 5. 평가
- 칸: 종목 배정 × 예측일 연도 홀/짝(과제 1-5와 같음).
- **검정 3개**
  1. B1(−Z) AUC > 0.5
  2. M AUC − B1 AUC > 0
  3. M 상위 10% 적중 − B1 상위 10% 적중 > 0 (예측일별 순위)
- p값: 예측일 단위 블록 부트스트랩 2,000회, 단측.
- 합격: 확인①·② 모두 p < 0.05 → 최종 칸 1회.

## 6. 반응 확인 (가)
- (a) 8-K 1.03 공시일 기준, SPY 대비
  - [−1, +1]
  - [−60, −2]
  - [−250, −2]
- 가격이 있는 경우만 본다. 상장폐지 회사 가격은 정리판이다.

## 7. 한계
- 장외로 밀려난 뒤의 가격은 일부만 있다.
- (b)의 기준(2달러, −70%)은 관례적 값이다. 결과를 보기 전에 고정했다.
- 거래대금 하한 때문에 아주 작은 회사의 부실은 빠진다.

  SEC 원본 companyfacts에서 총부채·이익잉여금·영업이익을 직접 읽어 넣는다. 가격 0에서 생긴 무한대 값은 결측으로 처리한다. 사건 연구(가)는 이미 출력을 봤다.
