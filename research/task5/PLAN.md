# 과제 5 — 재무제표 신호와 역DCF: 사전 등록 계획

> 작성·고정 2026-10-24 (결과 보기 전). 변경은 아래 "변경 이력"에만 날짜·이유와 함께 추가한다.
> 배경: 학계의 재무 이상현상(매출총이익률, 발생액, 자산 증가, 주식 발행, F-점수, 가치)과 역DCF를
> 이 데이터에서 다시 확인한다. 상당수는 논문 발표 뒤 약해졌다는 보고가 많다.

## 1. 데이터
- **유니버스**: 티커맵 개별 주식 중 미국 본사(현재 기준), 가격·재무가 있는 종목.
  금융(`sec` = Financial Services)과 부동산(Real Estate)은 재무 구조가 달라 제외한다.
- **재무**: R2 `sec/facts` (XBRL, 2009~).
  - **모든 값은 그 값이 처음 공시된 날 이후에만 쓴다.** 다음 해 비교 수치로 다시 실린 값은 쓰지 않는다.
  - 흐름 항목(매출·순이익·영업현금흐름·설비투자)은 최근 12개월(TTM)로 만든다.
    - 최근 보고가 연간이면 그 값을 쓴다.
    - 분기·누적이면 "직전 연간 + 올해 누적 − 작년 같은 기간 누적"으로 계산한다.
  - 잔액 항목(자산·부채·현금·자본)은 가장 최근 공시 값을 쓴다.
  - 매출 태그는 `Revenues` → `RevenueFromContractWithCustomerExcludingAssessedTax` → `SalesRevenueNet` 순으로 쓴다.
- 장기부채가 없으면 `LongTermDebtNoncurrent`, 둘 다 없으면 0으로 본다(역DCF 기업가치).
- **시가총액**: 과제 3과 같다(종가 × 발행주식수, 없으면 희석 가중평균 주식수, 200일 안 공시).
- **가격**: yfinance 수정주가. 기준은 같은 날 유니버스 동일가중 평균.
- **생존편향**: 상장폐지 종목이 없다. 연 약 1.2%p의 수준 편향이 측정돼 있다(survivorship/out). 신호와 얽힌 정도는 모른다.

## 2. 신호 (각 리밸런싱일, 그날까지 공시된 값만)
| ID | 정의 | 좋은 쪽 |
|---|---|---|
| GPA | 매출총이익(TTM) ÷ 총자산. 매출총이익이 없으면 매출 − 매출원가 | 높음 |
| ACC | (순이익 − 영업현금흐름)(TTM) ÷ 총자산 | 낮음 |
| AG | 총자산 1년 증가율 | 낮음 |
| ISS | 발행주식수 1년 증가율 | 낮음 |
| FS | F-점수 9점 (순이익>0, 영업현금흐름>0, ROA 개선, 영업현금흐름>순이익, 부채비율 감소, 유동비율 개선, 주식 미발행, 매출총이익률 개선, 자산회전율 개선) | 높음 |
|  | (F-점수: 9개 항목 중 8개 이상 계산되면 합계 × 9/계산된 항목 수, 7개 이하면 없음) |  |
| EY | 순이익(TTM) ÷ 시가총액 | 높음 |
| FCFY | (영업현금흐름 − 설비투자)(TTM) ÷ 시가총액 | 높음 |
| RDCF | 역DCF 내재 성장률 (아래) | 낮음 (시장 기대가 낮음) |
| RGAP | 내재 성장률 − 과거 3년 매출 연평균 성장률 | 낮음 (기대 < 과거 실적) |

**역DCF**: 기업가치 = 시가총액 + 장기부채 − 현금. 잉여현금흐름 FCF0 = 영업현금흐름 − 설비투자(TTM), FCF0 > 0인 경우만.
아래 식을 만족하는 10년 성장률 g를 구간 [−20%, +60%]에서 푼다. 할인율 r = 9%, 영구 성장률 2.5%로 고정.

  기업가치 = Σ_{t=1..10} FCF0·(1+g)^t/(1+r)^t + FCF0·(1+g)^10·(1.025)/(r − 0.025)/(1+r)^10

과거 컨센서스 이력이 없어서 "내재 성장률 vs 컨센서스"는 실시간 시험(BACKLOG)으로 넘긴다.

## 3. 포트폴리오와 목표
- **리밸런싱일**: 1·4·7·10월 첫 거래일, 2011-01 ~ 2025-10. 재무 1년 변화를 계산하려면 2년치가 필요하다.
- 각 날짜에 신호값이 있는 종목을 5분위로 나눈다. "좋은 쪽" 5분위를 동일가중으로 보유한다.
- **보유**: 63거래일(주), 252거래일.
- **목표 D** = 좋은 쪽 5분위 평균 수익 − 같은 날 신호값이 있는 전체 종목 평균 수익.
  참고로 좋은 쪽 − 나쁜 쪽(매수-공매도 차이)도 낸다.
- **검정 수**: 9 신호 × 2 보유 = **18개**.

## 4. 4칸과 판정
- 종목 A/B(과제 1과 같은 배정) × 리밸런싱일 연도 홀/짝. 칸마다 그 칸 종목만으로 5분위를 나눈다.
- 리밸런싱일 단위 t검정, 단측. 252일 보유는 기간이 겹쳐 실효 표본이 작다는 점을 감안해 Newey-West(시차 4)로 계산한다.
- **합격**: 설계 칸 D > 0 → 확인①·② 모두 D > 0 & p < 0.05, 그리고 좋은 쪽 5분위 원수익 − 왕복 0.1% > 0 → 최종 칸 1회.
- **참고 분할**(설계 칸): 시기(2011–15 / 2016–20 / 2021~), 시장 국면(SPY 200일선).

## 5. 한계
- 생존편향(가장 큼): 가치·부실 관련 신호(EY, FCFY, FS, ACC)는 망한 회사가 빠지면 좋아 보이기 쉽다.
- 유니버스가 현재 대형·중형주라, 이상현상이 강하다고 알려진 소형주가 없다.
- 홀/짝 해 분리는 252일 보유에서 시간이 겹친다.

## 6. 생존편향 재검증 R (2026-10-24 등록, 상장폐지 데이터로 결과를 보기 전)
- **유니버스(시점 기준)**: 현재 풀 ∪ EODHD 상장폐지 종목.
  - 상장폐지 종목은 SEC CIK가 하나로 연결되고 재무가 있는 경우만 쓴다.
  - SIC 6000–6799(금융·부동산)는 제외한다.
  - 각 리밸런싱일에 직전 252거래일 평균 거래대금(원종가 × 거래량)이 **2천만 달러 이상**인 종목만 넣는다. 현재 풀에도 같은 기준을 적용한다.
- **수익률**: 보유 중 가격이 끊긴 상장폐지 종목은 마지막 가격에서 현금으로 둔다.
  - 민감도: 마지막 60거래일에 50% 넘게 떨어진 채 끊기면 −30%를 추가로 적용한다(부실 상장폐지 가정).
- **4칸 배정**: 기존 종목은 기존 A/B를 쓴다. 상장폐지 종목은 코드의 MD5 첫 바이트 홀/짝으로 정한다(고정·결정적).
- 신호 9개·5분위·윈저화(1%/99%)·합격 기준은 §2~§4와 같다. 검정 18개를 새로 센다(log `T5R-`, 민감도는 `T5R30-`).
- 판단: 발생액(ACC)이 이 유니버스에서도 4칸을 통과하면 '살아남은 신호'로, 아니면 생존편향 산물로 본다.

## 7. 역DCF 표시용 정의 재검증 D (2026-10-25 등록, 결과 보기 전)
사용자에게 보여줄 역DCF 정의를 확정하고, 이 정의 **하나만** §6과 같은 규약으로 검증한다(변형 비교·선택 없음).
정의의 근거는 성과가 아니라 설명 가능성이다(2026-10-25 대화).

- **기업가치(EV)** = 시가총액 + 총차입금 + 리스 부채 + 소수주주지분 − 현금 − 단기투자.
  - 총차입금: 장기(비유동) + 유동성 장기부채 + 단기차입.
    `LongTermDebtNoncurrent`(없으면 `LongTermDebt`) + `LongTermDebtCurrent`(없으면 `DebtCurrent`) + `ShortTermBorrowings`
  - 리스: `OperatingLeaseLiability` + `FinanceLeaseLiability`
  - 소수주주지분: `MinorityInterest`
  - 현금: `CashAndCashEquivalentsAtCarryingValue`
  - 단기투자: `ShortTermInvestments`(없으면 `MarketableSecuritiesCurrent`)
  - 없는 항목은 0으로 본다.
- **출발 FCF** = 영업현금흐름 − 설비투자 − 주식보상비용(`ShareBasedCompensation`, 없으면 `AllocatedShareBasedCompensationExpense`, 없으면 0). 모두 최근 12개월.
  - 보정: 3년 평균(지금, 1년 전, 2년 전 시점의 최근 12개월 FCF 평균)과 50% 넘게 차이 나면 3년 평균을 쓴다(2년 전 값까지 있을 때만).
  - FCF ≤ 0이면 산출하지 않는다.
- **할인율(WACC)** = E/(E+D)·Ke + D/(E+D)·Kd·(1−t)
  - Ke = 10년 국채(FRED DGS10, 리밸런싱 전날) + 베타 × 주식위험프리미엄.
    - 주식위험프리미엄: Damodaran 미국 내재 ERP. 월별 값을 쓰고, 월별이 없는 기간은 직전 연말 값.
    - 베타: 직전 60개월 월간 수익률 대 SPY(최소 24개월). Blume 조정(0.67β + 0.33), 0.5~2.0으로 제한. 데이터가 부족하면 1.0.
  - Kd = 이자비용(최근 12개월) ÷ 총차입금. 국채금리 ~ 국채금리+6%p로 제한하고, 없으면 국채금리 + 1.5%p.
  - t = 법정 최고세율(2017년까지 35%, 2018년부터 21%). D = 총차입금 + 리스.
- **기간 구조**: 1~5년은 성장률 g, 6~10년은 g에서 2.5%로 매년 같은 폭으로 감소, 이후 2.5% 영구.
  WACC < 3.5%면 산출하지 않는다. g는 [−50%, +100%] 안에서 푼다.
- **신호**: g 낮은 쪽 5분위(좋은 쪽). §6 유니버스(R, 상장폐지 포함·거래대금 하한), 윈저화, 4칸, 합격 기준 그대로.
  검정 2개(3개월·1년). log `T5D-`.
- **표시 규칙(검증과 무관)**: g < −10% 또는 > +50%는 "범위 밖"으로 표시. 금융·리츠와 FCF ≤ 0은 사유와 함께 "산출 불가".
