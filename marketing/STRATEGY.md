# 티커맵 홍보 전략

> 2026-10-26 정리. 카드·글 자동 생성기(`hub/cards.py` 등)는 이 문서와 `marketing/headlines.json`(제목 틀·금지 표현)을 따른다.
> 저장소가 공개라 이 문서도 공개된다. 민감한 수치(가입자·매출 등)는 여기에 적지 않는다.

## 1. 방향
- 광고 없이 좋은 정보로 천천히 인지도를 쌓는다. 결제를 미는 느낌은 주지 않는다.
- 추천·예측은 하지 않는다. "사라"가 아니라 "이런 점을 확인하라".
- 사이트 원칙과 같다: '검증' 표시 금지, 방향(오를지/내릴지) 표시 금지, 과거 통계는 짧은 문장으로.

## 2. 핵심 메시지
**미국 주식에서 확인할 거리를 한국어로, 매일 자동으로 정리해 주고, 추천 대신 근거와 과거 기록을 보여 준다.**

## 3. 강점
| # | 강점 | 근거가 되는 기능 |
|---|---|---|
| 1 | 종목 한 장 분석 | 컨센서스 13개 지표(같은 산업 순위·경쟁사 비교 차트), SEC 원문 재무 5년·12분기, 실적 결과와 반응, ETF 비중 변화, 13F, 내부자, 10-K 위험요인 변화, 뉴스 톤, 점검표, 배당 점검, 부실 등급, 지수 근접도. 1,035개 종목 정적 페이지(/s/티커/)는 검색 입구 |
| 2 | 어긋남 지도(티커맵) | 주가와 신호(EPS 전망·매출 가속·유명 투자자·내부자·공매도)가 엇갈린 종목을 한 장으로. 다른 곳에 없는 대표 기능 |
| 3 | 실적 시즌 한눈에 | 실적 달력, 옵션 예상 변동 vs 지난 8번 평균, 같은 업종 이번 시즌 반응, 발표 결과 한 마디 |
| 4 | 위험 점검 | 부실 위험 등급, 배당 삭감 점검, 행동주의·피인수·파산 공시 알림 (과거 통계와 함께) |
| 5 | 배당 점검 | 인상 시기 패턴("매년 11월경 인상"), 연속 무삭감, 배당수익률 구간별 과거 삭감 비율 |
| 6 | 내 전략 점검(포트폴리오) | ETF 안까지 펼친 실제 노출, 위기 구간(2008·2020·2022), 원화 기준 적립식, "그대로 뒀다면" 비교, 공유 링크 |

## 4. 톤 원칙 — "제목은 강렬하게, 숫자는 정확하게, 근거는 마지막에"
- 강렬함은 예측이 아니라 **사실의 대비**에서 가져온다(대비·질문·순위·이례적 사실).
- 카드 구성
  1. 첫 장(멈추게): 큰 글씨 한 줄 + 큰 숫자 하나
  2. 가운데 장(이해시키게): 한 장에 메시지 하나, 막대·순위, 종목 5개 이하
  3. 마지막 장(믿게): 정의·기준일·과거 통계·출처·"정보 제공용이며 투자 권유가 아닙니다"
- 종목 하나를 다룰 때는 좋은 신호와 경고를 같은 카드에 함께 둔다. 고른 기준(실적 발표·조회수 등)을 카드에 적는다.

| 써도 됨 (사실의 대비) | 쓰면 안 됨 (예측·권유) |
|---|---|
| "주가는 −20%, 이익 전망은 +15%" | "저평가, 지금이 기회" |
| "2006년 이후 한 번도 안 깎았다" | "평생 배당 받을 종목" |
| "목요일 하루에 124개 회사가 실적 발표" | "실적 대박 예상 종목" |
| "옵션 시장은 평소의 3배 출렁임을 걸었다" | "급등 임박" |
| "배당 6% 넘는 회사, 과거 4곳 중 1곳은 1년 안에 깎았다" | "이 종목 배당 곧 깎인다" |
| "S&P 500 문 앞에 선 회사 TOP 10" | "편입 수혜주, 미리 사 두세요" |

## 5. 정기 연재
| 연재 | 주기 | 내용 | 데이터 | 자동화 |
|---|---|---|---|---|
| 어긋남 지도 | 매주 | 이번 주 렌즈의 엇갈린 종목 5개 | universe·trails | 완전 자동 (지금 `cards.py`) |
| 이번 주 실적 달력 | 매주 월요일 | 주요 발표 일정, 옵션이 평소보다 크게 보는 종목 | c_next·er_imp·er_avg·em_ind | 완전 자동 |
| 실적 결과 정리 | 시즌 중 매주 금요일 | 이번 주 발표의 상회·하회와 반응 | er_d·er_eps_s·er_rev_s·er_mv | 완전 자동 |
| 종목 한 장 해부 | 매주 3~5개 | 실적 발표 대형주·많이 본 종목·크게 움직인 종목 | 종목 상세 | 완전 자동, 첫 장 제목은 가장 이례적인 사실을 자동 선택 |
| 배당 캘린더 | 매월 초 | 이달 인상 패턴 회사, 삭감 점검에 걸린 고배당주 | dvc_* | 완전 자동 |
| 공시 이슈 | 사건 있을 때 | 행동주의 13D, 피인수 확정 | events | 자동 생성 + 올리기 전 확인 |
| S&P 500 문 앞 | 분기 초 | 요건 충족 비구성 시총 TOP 10 + 지난 분기 목록 적중 | ix_sp, universe 스냅샷 | 완전 자동 |
| 신호 성적표 | 분기 초 | 지난 분기에 표시한 부실 등급·배당 점검·편입 목록의 실제 결과(맞은 것과 틀린 것 모두) | research_live | 완전 자동 (2027-01부터) |
| 위기 테스트 | 수시 | "당신 포트폴리오, 2008년이었다면?" → 사이트 포트폴리오로 유도 | 포트폴리오 시뮬레이션 | 반자동 |

- "종목 한 장 해부" 첫 장 제목 후보: 같은 산업 안 순위가 극단(1위·꼴찌), 주가와 신호의 엇갈림, 평소 대비 이례적 크기(거래량·옵션 예상 변동). 가장 이례적인 것을 고른다(주간 리포트 '평소와 다른 일'과 같은 방식).
- 신호 성적표는 리딩방과 반대로 "채점된 기록"을 공개하는 장기 핵심 콘텐츠다.

## 6. 만드는 흐름과 채널
1. 매주 수집이 끝나면 카드 이미지(인스타 1080×1350 캐러셀, 가로 1600×900)와 본문 생성
2. 텔레그램으로 미리 받아 확인 → 한 번 눌러 게시 (한두 달 문제없으면 일부 채널 완전 자동)
3. 블로그용 글은 사이트 정적 페이지·RSS로 함께 내보냄

| 채널 | 게시 방식 |
|---|---|
| 스레드 | 공식 API — 승인 뒤 자동 게시 가능 |
| 인스타그램 | 비즈니스 계정 연결 시 API 게시 |
| X | API 유료 → 수동 또는 보류 |
| 네이버 블로그 | 글쓰기 API 없음 → 생성된 글 복사·붙여 넣기 |

## 7. 안전장치
- 제목은 `headlines.json`의 검토된 틀에서만 고르고 숫자만 끼운다(자유 문장 생성 금지).
- 금지 표현이 들어가면 생성을 멈추고 텔레그램으로 알린다.
- 회사 로고는 쓰지 않는다(티커·한국어 이름만).
- 같은 데이터로 제목 틀 2~3개를 번갈아 써서 반응을 보고 강도를 조절한다.
- 유료화 전 법률 검토 때 홍보 문구도 함께 본다(유사투자자문업).

## 8. 성과 지표
- 카드: 저장·공유·댓글 수(좋아요보다 저장·공유를 우선)
- 유입: 사이트 방문(유입 경로별), 종목 페이지 조회, 공유 링크 열림
- 전환: 관심 종목 담기, 로그인, 텔레그램 알림 연결, 포트폴리오 생성
- 매월 연재별로 위 지표를 보고 주기·제목 틀·강도를 조정한다.
